## Projects

### KKBox churn analysis: is KKBox losing subscribers or dropping them?
Group project analysing voluntary versus billing-related churn across two monthly cohorts.
- Tools: Python, DuckDB, SQL, Tableau
- Data: KKBOX WSDM Cup 2018 (Kaggle), not included in this repository
- Dashboard: https://public.tableau.com/app/profile/shriya.virendra.wadetwar/viz/dashboardUpdatedUI/KKboxdashboard
